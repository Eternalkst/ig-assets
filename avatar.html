Контент на автопилоте: рилсы без съёмки

Как устроена моя система: я не снимаю, не озвучиваю, не монтирую и не выкладываю — только нажимаю «ок» в Telegram. Ниже — всё, что для этого нужно, честно: сервисы, подписки, установка и подводные камни.

сценарий→ ваш голос→ ваш аватар→ монтаж→ обложка→ «ок» в Telegram→ Instagram→ ответы на комментарии

Пошагово

0

Подготовка компьютера

  1. Установите приложение Claude (вкладка Code — это Claude Code) и оформите подписку.
  2. Установите Node.js (LTS) и Git, затем ffmpeg.
  3. Создайте папку проекта и проект Remotion: npx create-video@latest.
  4. Поставьте Whisper (whisper.cpp, модель large-v3-turbo) — он расшифровывает озвучку: по нему делаются субтитры по словам и проверяется, что ни одно слово не обрезано.
  5. Попросите Claude создать для вас навык (skill) монтажа: правила вашего стиля, порядок смыслов в ролике, цвета, шрифты, звуки. Тогда каждый следующий ролик собирается одинаково хорошо.
1–2 вечера
1

Ваш голос — копия в ElevenLabs

  1. Тариф Creator (быстрая копия голоса доступна дешевле, но звучит заметно хуже).
  2. Запишите 30–60 минут речи на диктофон: часть читаете, часть рассказываете своими словами, с разными эмоциями. Тихая комната, телефон в 15–20 см ото рта, всё в одних условиях.
  3. Voices → Add a new voice → Professional Voice Clone → загрузите файлы, подтвердите, что голос ваш (прочитаете фразу). Обучение — несколько часов.
  4. Создайте API-ключ с правами Text to Speech, Voices (чтение), User (чтение) и Sound Effects — Claude будет озвучивать и делать звуки сам.
  5. Проверьте модели: у меня похожим получился голос на eleven_v4.
Подводный камень: ударения и названия. Нейросеть может сказать «Кастанай» вместо «Костанай». Каждую озвучку прогоняйте через распознавание и слушайте проблемные слова.
2

Цифровой двойник — HeyGen

  1. Нужен платный тариф: на бесплатном — водяные знаки по всему кадру, 720p и нельзя генерировать образы.
  2. Загрузите своё фото (чёткое, свет на лице, нейтральный фон) — получите фото-аватара. Лучше ещё снять 2–5 минут видео для цифрового двойника: он даёт естественные движения.
  3. Подключите HeyGen к Claude как коннектор (MCP): claude.ai → Настройки → Connectors → добавить https://mcp.heygen.com/mcp/v1/ и войти. Тогда Claude сам загружает озвучку и заказывает видео.
  4. Видео делается так: ваша озвучка из ElevenLabs → аватар двигает губами под неё. Лучший результат у меня — движок Avatar V с двойником в качестве образца движений.
Подводный камень: не каждый образ похож на вас. Генерируйте несколько, оставляйте только те, где вы узнаваемы, иначе зрители чувствуют «не то».
3

Сценарий по формуле

Схема, которая держит внимание: цепляющее начало (2 сек) → кто вы и для кого → боль → решение → доказательство → призыв с ключевым словом. Пишите живой речью, короткими фразами, 30–60 секунд. Числа и названия — так, как их надо произнести.

4

Монтаж в Remotion

  1. Шаблон ролика: аватар на весь экран, над головой — графика на каждый смысл (то, что зритель слышит, он тут же видит).
  2. Субтитры по словам с выделением ключевых — по таймингам из Whisper.
  3. Переходы между смысловыми блоками, лёгкая музыка под голосом, звуковые эффекты (ElevenLabs Sound Effects).
  4. Рендер 1080×1920, проверка кадров и финальная проверка звука распознаванием.
с готовым шаблоном — 20–40 минут на ролик, почти без вашего участия
5

Обложка и описание

Обложка — кадр в стиле вашего профиля (важное — в центре 1080×1440, иначе обрежется в сетке). Описание — короткое, с пользой и ключевым словом для комментариев.

6

Instagram API: доступ к публикации

  1. Instagram переводится в профессиональный аккаунт (автор или бизнес).
  2. На developers.facebook.com создаётся приложение со сценарием «Instagram API со входом через Instagram», добавляются права на публикацию контента, комментарии и сообщения.
  3. Генерируется токен (живёт 60 дней) — его нужно продлевать, иначе через два месяца всё молча встанет. У меня бот продлевает его сам раз в неделю.
  4. Видео и обложку Instagram берёт только по публичной ссылке — их выкладывают, например, на GitHub Pages.
Подводный камень: пока приложение Meta в режиме разработки, автоответы видят только вы и тестировщики. Чтобы бот отвечал всем, приложение проходит проверку Meta (App Review) — от нескольких дней до пары недель.
7

Telegram-бот: подтверждение → публикация

  1. Создаёте бота в @BotFather, получаете токен.
  2. Бот размещается на Cloudflare Workers (бесплатно) с базой данных.
  3. Готовый ролик приходит вам: видео, обложка, текст и кнопки ✅ видео · ✅ обложка · ✅ текст.
  4. Когда всё ✅ — бот создаёт рилс в Instagram, ждёт, пока Instagram обработает видео (1–3 минуты), публикует и присылает вам ссылку.
8

Ответы на ключевое слово

Отдельный бот на Cloudflare получает от Meta уведомления о комментариях (webhook): человек пишет слово → бот отвечает в комментарии «отправил в директ» → в директе просит подписаться, проверяет подписку и выдаёт материал. Так рилс приводит подписчиков и заявки без вас.

9

Поток: каждый день

Дальше рутина такая: вы даёте тему → Claude пишет сценарий → озвучивает → заказывает аватара → монтирует → делает обложку и текст → присылает в Telegram → вы нажимаете «ок» → рилс выходит. Ваша часть — 1–2 минуты.

Честно: собрать это самому — непросто

Это 8–10 сервисов и программ, которые нужно связать между собой: голос, аватар, монтаж, токены Meta, проверка приложения, два бота, хостинг, продление токенов. У меня на первую настройку ушли недели — и много нюансов, которые всплывают только в процессе.
